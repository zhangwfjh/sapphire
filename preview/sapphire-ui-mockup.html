Apple shows off on-device 3B-parameter model running offline on M4
curated by sapphire · classified: AI & ML

At its annual hardware event, Apple demonstrated a 3-billion-parameter language model executing entirely on the Neural Engine of the M4 chip — no network round-trip, no server GPU, no telemetry leaving the device.

在年度硬件发布会上，苹果展示了一个 30 亿参数的语言模型，完全在 M4 芯片的神经引擎上离线运行 —— 没有网络往返，没有服务器 GPU，没有任何遥测数据离开设备。

The model, quantized to 4-bit weights, occupies roughly 1.8 GB of unified memory and sustains upward of 40 tokens per second during streaming generation. Engineers attributed the throughput to a redesigned KV-cache layout that exploits the M4's increased matrix-multiply bandwidth.

该模型采用 4-bit 量化权重，占用约 1.8 GB 统一内存，在流式生成时吞吐量超过每秒 40 token。工程师将这一吞吐归功于重新设计的 KV-cache 布局，充分利用了 M4 提升的矩阵乘法带宽。

What makes the demonstration quietly significant is not the raw speed but the accessibility: the same model ships in the open-source release accompanying the platform, letting third-party developers embed local inference without licensing a frontier API.

让这次演示意义深远的并非原始速度，而是可及性：同一模型随平台的开源版本一同发布，让第三方开发者无需授权前沿 API 即可嵌入本地推理。

Benchmarks shared at the session place the model within striking distance of GPT-3.5 on common-sense reasoning tasks while falling behind on knowledge-intensive retrieval — a deliberate trade for a model that must fit, and stay, on a phone.

会上分享的基准测试表明，该模型在常识推理任务上接近 GPT-3.5，但在知识密集型检索上落后 —— 这是为一个必须装进并驻留在手机上的模型所作的刻意权衡。
